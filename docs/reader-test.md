# README 读者测试（v0）

> **诚实说明**：本版由实现者按 README 逐条走查 + 一次真实的全新 clone 执行，**不是第三方读者**。
> 它能证明"照着做能跑通"，**不能**证明"陌生人第一遍就看得懂"。后者是下面的缺口。

- 环境：Windows 11 · Windows PowerShell 5.1 · Python 3.11.9
- 方法：清空目标目录 → `git clone` → **只按 README 的文字顺序操作**，不靠记忆补步骤；每步记录实际输出与是否卡住
- 日期：2026-11-07（首轮）／2026-11-08（修复后复测）

## 一、逐条结果

| # | README 步骤 | 预期 | 实际 | 结论 |
|---|---|---|---|---|

## 二、这一轮修掉的（都来自"照着做"暴露的问题）

1. **README 安装段**拆成「运行依赖 / 开发依赖」两段，并明确警告：只装 `requirements.txt` 跑不了 pytest。
2. **`check.ps1` 解释器定位**：优先用项目 `venv`，不再依赖终端是否激活（修 9009）。
3. **`check.ps1` 编码**：改存 UTF-8 **带 BOM**。Windows PowerShell 5.1 会把无 BOM 的 UTF-8 按 GBK 解码，中文注释行末的标点可能吃掉换行，导致**下一行代码整行变成注释的一部分**——那条"缺 pytest 就提示"的 guard 因此从来没执行过，脚本却一直"看起来正常"。这类问题只有真跑才会现形。
4. **双入口**：README 顶部加了对照表，两个 `.py` 文件头部互相指路。
